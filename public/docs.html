Six-Stage Extraction, Entity Intelligence & Playback Pipeline

How Sportify v1.3.0 transforms raw encrypted CS3 payloads into low-latency, normalized sports feeds.

STAGE 01 Firebase & Mirror Discovery
Parallel Provider Ingestion

Queries Firebase Remote Config (:fetch) and bootstrap mirrors across all 6 CS3 providers concurrently with per-provider Circuit Breakers and Singleflight request coalescing.

STAGE 02 In-Memory Dalvik Ciphers
Native Bytecode Decryption

Executes exact classes.dex algorithms: SXR3 ChaCha20 sponge + MAC verification, 256-byte Table D + V23 substitution, FNV-1a key derivation, byte-pair swaps, and AES-128-CBC.

STAGE 03 Unicode & Entity Hygiene
Entity & League Inference

Folds Unicode diacritics (Türkiye → Turkiye), separates match vs tournament_channel, infers leagues from franchises (WBBL, IPL, BBL, PSL), and computes order-independent canonical keys.

STAGE 04 Lossless Coalescing
Multi-Provider Stream Merging

Normalizes stream URLs by stripping ephemeral cache-busters while preserving signed CDN tokens. Merges identical streams across providers, combining ClearKey DRM keys, HTTP headers, and provenance badges.

STAGE 05 24KB Manifest Prober
Deep HLS/DASH Inspection

Parses up to 24KB of HLS Master/Media and DASH MPD manifests to extract real video renditions, audio tracks, encryption schemes (CLEARKEY, AES-128, CENC), low-latency flags, and segment counts.

STAGE 06 6-Scheme Edge Proxy
Adaptive Proxy & Failover

Resolves all 6 custom schemes (cricify://, sportzx://, sktech://, playztv://, livxow://, playfy://), rewrites child URLs, filters quality, and micro-caches segments.

Playback Compatibility & 6-Scheme Edge Proxy Engine

Every RichStreamFeed includes a deterministic playbackCompatibility descriptor so web, mobile, and IPTV players know exactly how to initialize playback without trial-and-error.

HLS + Edge Proxy Rewriting

When streaming HLS (protocol: "hls") in browsers or webviews, use network.edgeProxyFallbackUrl. The proxy injects required upstream Referer, User-Agent, Origin, Cookie, and Authorization headers, rewrites child playlists, and automatically fails over to &fallback= mirrors on HTTP 5xx/timeout.

MPEG-DASH + ClearKey DRM

When playbackCompatibility.requiresClearKeyDrm is true, initialize Shaka Player or ExoPlayer with the hex kid/key pairs in feed.drm.clearKeys. All ClearKey pairs are normalized to lowercase 32-char hex and validated from hex, base64url, or JWK formats.

IPTV M3U8 + XMLTV EPG

Point TiviMate, OTT Navigator, or Kodi to /api/playlist.m3u and /api/epg.xml. Sportify emits #KODIPROP:inputstream.adaptive.license_key and #EXTVLCOPT directives automatically and resolves deferred schemes on tune-in.

              1. TypeScript SDK — Resolve & Auto-Select Player
              v1.3.0
            

            
const res = await fetch("/api/matches/live?sport=cricket");
const { matches } = await res.json();

if (matches.length > 0) {
  const key = encodeURIComponent(matches[0].canonicalKey);
  const streamRes = await fetch(`/api/stream/${key}?probe=true`);
  const { feeds } = await streamRes.json();
  const primary = feeds[0];

  if (primary?.playbackCompatibility?.recommendedPlayer === "shaka-player") {
    // Configure Shaka Player with primary.drm.clearKeys
    console.log("DASH ClearKey Feed:", primary.network.masterPlaylistUrl);
  } else if (primary) {
    // Play CORS-safe rewritten HLS via Edge Proxy
    console.log("HLS Edge Proxy URL:", primary.network.edgeProxyFallbackUrl);
  }
}

const player = new shaka.Player(videoElement);

if (feed.drm?.clearKeys?.length) {
  const clearKeysMap = Object.fromEntries(
    feed.drm.clearKeys.map(({ kid, key }) => [kid, key])
