Sportify Platform Documentation • Release v1.1.0

Federated Live Sports & Stream Aggregation Engine

Sportify v1.1.0 is a high-availability sports data and stream aggregation API built on Bun and Hono. It queries six reverse-engineered CloudStream3 (CS3) providers concurrently, decrypts upstream payloads in memory, reconciles inconsistent event titles into order-independent canonical fixtures, parses real HLS/DASH manifests for video renditions and ClearKey DRM, and serves sub-millisecond O(1) indexed & Stale-While-Revalidate (SWR) cached responses.

Event Identity, Franchise Inference & Stream Deduplication

1. Order-Independent Reconciliation

Titles such as New Zealand vs India, IND vs NZ, and NZ vs IN resolve to the same canonical key cricket::ind-vs-nz::YYYY-MM-DD. Distinct match numbers (1st ODI vs 2nd ODI), genders (INDW vs IND), and age groups (INDU19) never falsely merge.

2. Franchise-to-League Inference

When an upstream title omits the competition name (e.g. Adelaide Strikers Women vs Sydney Sixers Women or CSK vs MI), the entity engine infers the parent tournament (Women's Big Bash League (WBBL) or Indian Premier League (IPL)) from the participating franchises.

3. Lossless Stream Deduplication

Stream URLs are normalized by stripping ephemeral cache-buster query tokens while preserving signed CDN tokens. When multiple providers serve the same stream, Sportify coalesces them into a single RichStreamFeed, merges ClearKey DRM keys and HTTP headers, and records full multi-provider attribution.

Filtering, Pagination & Error Structure

Query Parameters Across Collection Endpoints
  • sport: cricket, football, motorsport, tennis, mma, wwe, kabaddi, basketball
  • phase: live | upcoming | ended | all
  • tournament: Tournament ID or shortName (e.g. tourn_ipl, wbbl, ucl)
  • team: Canonical team code or alias (e.g. IND, NZ, CSK, STRW)
  • provider: cricify | sportzx | playztv | playfy | sktech | livxow
  • page & limit: 1-indexed pagination (default limit=50, max=250)

Client Integration Examples

TypeScript / Fetch SDK
const res = await fetch("http://localhost:3000/api/matches/live?sport=cricket");
const { matches } = await res.json();

if (matches.length > 0) {
  const key = encodeURIComponent(matches[0].canonicalKey);
  const streamRes = await fetch(`http://localhost:3000/api/stream/${key}?probe=true`);
  const { feeds } = await streamRes.json();
  console.log("Primary Playable URL:", feeds[0]?.network.edgeProxyFallbackUrl);
}
cURL & jq CLI
# Query live cricket matches involving India
curl -s "http://localhost:3000/api/matches?sport=cricket&team=IND" | jq '.matches[] | {title, canonicalKey, schedule}'

# Cross-resource unified search
curl -s "http://localhost:3000/api/search?q=WBBL" | jq '.tournaments, .matches'
