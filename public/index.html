Order-Independent Canonical Keys

"IND vs NZ" and "New Zealand vs India" automatically merge into the exact same canonical fixture (cricket::ind-vs-nz::2026) with shared feeds.

Zero Fake Teams in Leagues

Intelligently separates head-to-head matches from tournament broadcasts (like Nepal Premier League, WBBL, Formula 1). Sets teams: null and outputs clean league metadata.

Multi-Provider Provenance

Identifies when feeds are shared across providers, assigning badges like "Multi-Source (Cricify + 2 Mirrors)" or "Exclusive to LivXow" with reliability rankings.

HLS Edge Proxy & CORS Rewriting

Built-in /api/proxy handles upstream Referer spoofing, rewrites child M3U8 playlists on-the-fly, and injects CORS headers for seamless web playback.

API Documentation

REST Endpoints Specification

Strictly typed endpoints following Sportify Live Sports Gateway v1.0.0.

Base: http://localhost:3000
Method & Path Query Parameters Description Cache Policy
GET /health — Arena Edge Gateway metadata, circuit breaker status, uptime, and endpoints map. No cache (live)
GET /api/catalog sport, phase, search, limit Unified normalized sports fixtures with order-independent canonical keys, league channel separation, and provider pointers. 90s TTL + SWR
GET /api/catalog/:sport — Filters unified fixtures by specific sport (e.g. /api/catalog/cricket). 90s TTL + SWR
GET /api/sports — Returns list of active sports with total fixture counts and live counts. 90s TTL + SWR
GET /api/stream/:fixtureKey protocol, quality, probe Resolves playable feeds with multi-provider provenance (attributionBadge, sourceList, priorityTier, reliabilityScore, ClearKey DRM, and renditions). Live Cached
GET /api/proxy url, quality, referer, ua HLS/DASH edge stream proxy that rewrites internal playlist URLs, strips unwanted resolutions, and injects CORS headers. Pass-through + micro-cache
GET /api/playlist.m3u sport Generates IPTV playlist file compatible with Kodi, TiviMate, OTT Navigator, and VLC. Live Dynamic
GET /api/live/sse — Real-time SSE event stream broadcasting match start alerts and score heartbeat ticks. Streaming SSE
